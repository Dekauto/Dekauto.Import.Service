# 🟣 Dekauto.Import.Service

Сервис импорта данных для системы автоматизации деканата. Отвечает за парсинг Excel-файлов и преобразование данных в объекты.

---

## 🔸 Функциональность

- **Приём файлов** - Получение Excel-файлов от сервиса "Студенты"
- **Парсинг данных** - Поиск и извлечение необходимой информации из файлов
- **Формирование объектов** - Сборка данных в структурированные объекты
- **Возврат результатов** - Передача объектов обратно в сервис "Студенты"

## 📋 Формат Excel-файлов

### Общие требования
- Заголовки столбцов должны находиться в первой строке
- Порядок столбцов не имеет значения
- Регистр заголовков не имеет значения
- Заголовок "ФИО" обязателен для заполнения

### 📄 Карточка студента (парсинг для приложения к диплому)

Pipeline card-import (parity с **DekautoDesktop 1.11.0+**): карточка «Ро…» + учебный план → `BuildDisciplineResultsFromPlanAndCard` → export приложения.

На листах **«Ро…»** (`ParseEducationResultsWorksheet`):

- Якорь «№ п/п»; gate двухрядной шапки (ordinal col как `1` / `1,0`, не текст «№ п/п») — parity с Desktop `StudentCardParser`.
- **col+2** — з.е. (`CreditUnits`, литерал `"X"` → `0`), **col+3** — всего часов (`TotalHours`), **col+4** — контактные часы (`AudHours`).
- **col+6** — тип контроля, **col+7** — оценка.
- Числа через `TryGetCardCellDouble` (без `GetValue<double>()` на `"X"`).

**B14 приложения (направление подготовки):** `ОбщСведения!C78` → `CourseOfTraining`; если в C78 только наименование без кода `XX.XX.XX`, код подставляется из листа **«Справочник»** `C3` (`ResolveSupplementCourseOfTraining`).

Учебный план (`plan`, лист «ПланСвод» + «Курс N»): **col 7/22** — тип контроля; **col 8/9/23/24** — всего и контактные часы. З.е. и часы в приложение к диплому берутся из плана, не из карточки.

### 📄 Личное дело

**Обязательные заголовки:**

- [x] ФИО
- [x] Пол
- [x] Дата рождения
- [x] Место рождения
- [x] Телефон
- [x] E-mail

- [x] Серия документа удостоверяющего личность
- [x] Номер документа удостоверяющего личность

- [x] ОВДДокумента удостоверяющего личность
- [x] Код подразделения документа удостоверяющего личность

- [x] Гражданство
- [x] Предмет1
- [x] Предмет2
- [x] Предмет3
- [x] Сумма баллов за инд.дост.(конкурсные)

- [x] Адрес по прописке
- [x] Адрес проживания
- [x] Конкурсная группа 
- [x] Направление\специальность

- [x] Серия документа об образовании
- [x] Номер документа об образовании
- [x] Дата выдачи

- [x] Год завершения
- [x] Тип документа об образовании
- [x] Образовательное учреждение

**Особенности формата:**

- ФИО: `Фамилия-Имя-Отчество` (дефис для составных частей)

  Пример: `Михаил Евграфович Салтыков-Щедрин`

- Элементы адреса должны разделяться запятыми
- Элементы адреса должны иметь следующий формат и порядок:
  1.	Индекс – шестизначное число. 
  2.	Название населенного пункта и его тип. Не разделяются запятой. Типы возможных населенных пунктов и их расшифровки:
    - г – город  
    - с – село  
    - х – хутор  
    - д – деревня  
    - п – посёлок  
  3. Улица
  4. Дом – обозначается как д. «номер дома». 
  5. Вид обособленности дома, всего их два:
      - к. – корпус
      - стр. – строение
  6. Квартира – обозначается как кв.
  
  Пример:
  `123456, Москва г, муниципальный округ Морозово, проезд Мушкинский, д. 15, к. 2, кв. 777`

### Для файла «Журнал регистрации договоров»

### Для файла «Журнал учета выдачи»

1. ФИО студента
2. № студ.билета и зачетной книжки

**Особенности формата:**

- ФИО: `Фамилия-Имя-Отчество` (дефис для составных частей)

  Пример: `Михаил Евграфович Салтыков-Щедрин`

># ℹ️ О Dekauto
>### Что такое Dekauto?
>Dekauto - это web-сервис, направленный на автоматизацию некоторых процессов работы деканата высшего учебного заведения. На данный момент система специализирована для работы в определенном ВУЗе и исполняет функции хранения, агрегации и вывода данных студентов. Ввод осуществляется через Excel-файлы определенного формата. Выводом является Excel-файл карточки студента с заполненными данными.
